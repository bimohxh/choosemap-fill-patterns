# ChooseMap Fill Patterns

Dependency-free JavaScript helpers for matching SVG and Canvas fills: dots, diagonal hatching, horizontal lines, vertical lines, and concentric rings.

Extracted from the fill-pattern renderer used by [ChooseMap](https://choosemap.com/), a map library and editor for styling maps and exporting editable SVG or PNG. This small project contains the renderer and a standalone demo with synthetic shapes; geographic datasets and the main application are not included.

## Run the demo

Clone or download this repository, then serve this directory:

```sh
python3 -m http.server 8080
```

Open http://localhost:8080/ in a modern browser. Choose a pattern and color, compare the SVG and Canvas previews, and download an editable SVG. No build step or package installation is required. Opening the HTML through `file://` may block ES module imports, so use the local server.

## Use SVG patterns

```js
import { fillPatternSpec, patternSvg } from './fill-patterns.js';

const spec = fillPatternSpec('hatch', '#245c47', 640, 400);
const definition = patternSvg(spec, 'coverage-hatch');
const svg = `<svg xmlns="http://www.w3.org/2000/svg" viewBox="0 0 640 400">
  <defs>${definition}</defs>
  <path d="M80 80H560V320H80Z" fill="url(#coverage-hatch)"/>
</svg>`;
```

Use a unique pattern ID for each definition in a document. `solid` and unknown styles return `null`; apply the solid color directly in those cases.

## Use Canvas patterns

```js
import { drawFillPattern } from './fill-patterns.js';

const region = new Path2D('M80 80H560V320H80Z');
ctx.save();
ctx.clip(region);
drawFillPattern(ctx, 'hatch', '#245c47', 640, 400);
ctx.restore();
```

The helper changes drawing state (including global alpha). Wrap calls in `save()` / `restore()`, and supply finite positive canvas dimensions. The Canvas function requires browser `Path2D` and `DOMMatrix` support. Draw solid fills directly with `ctx.fill()`.

## API

- `FILL_STYLES`: available IDs and labels, including `solid`.
- `fillPatternSpec(style, color, width = 640, height = 400)`: shared vector specification; rings center on the supplied dimensions.
- `patternSvg(spec, id)`: SVG `<pattern>` markup for a spec generated by this module. Attribute values are escaped; this is not a sanitizer for arbitrary SVG specifications.
- `drawFillPattern(ctx, style, color, width = 640, height = 400)`: draw across a Canvas surface; clip to your region first.
- `ringRadii(height, width = 640)`: radii covering the rectangle's corners.

## Example uses

Distinguish map coverage areas without relying solely on color, create hatched chart regions, or keep a Canvas preview consistent with a vector export. Check contrast and include a legend for your own design.
